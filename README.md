
# LAN Connect

Simple QR-based peer-to-peer mobile connection.

## Features

- QR code pairing
- Two-device connection
- Live messaging
- File sharing (up to 10 MB)
- Basic screen sharing support
- WebRTC communication

## Installation

Install Node.js.

Run:

```bash
npm install
npm start
```

Open:

http://localhost:3000

For online hosting, deploy the project
using Render.

Build command:

npm install

Start command:

npm start
